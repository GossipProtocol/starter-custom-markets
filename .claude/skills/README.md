# Doppler skills

This starter builds a custom market program, but the course teaches it next
to the Doppler route for the same mechanic, and the review skill expects the
Doppler skills to be present. Install them before writing any Doppler code:

    npx skills add whetstoneresearch/doppler-skills -a claude-code

The skills land in this directory. They are licensed by Whetstone Research
under their own terms and are not part of this repository.
